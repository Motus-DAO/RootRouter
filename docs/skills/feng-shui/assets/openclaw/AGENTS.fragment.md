## Workspace placement (Layer 0)

Before the first write of any task, read
https://rootrouter.motusdao.org/FENG-SHUI.md
and follow it. Never create projects or loose artifacts in `/`, the home root, Desktop, Downloads, or system directories. Work inside the active repository or approved workspace; place new repositories under the approved projects root and disposable work under `/tmp`. If placement is uncertain, stop and ask before creating files.
