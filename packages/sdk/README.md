# rootrouter

Algebraic agent infrastructure for AI agents — context selection, native repo graph, root-pair telemetry, and model routing.

**Early beta** — see [BETA.md](./BETA.md). MIT license — see [LICENSE](./LICENSE). Commercial surfaces: [COMMERCIAL.md](./COMMERCIAL.md).

## Quick start

```bash
npm install rootrouter@beta @rootrouter/proxy@beta @rootrouter/mcp@beta
npx rootrouter@beta index ./my-repo
npx rootrouter@beta init cursor
npx -p @rootrouter/proxy@beta rootrouter-proxy
```

Full documentation: https://github.com/RootRouter/RootRouter
